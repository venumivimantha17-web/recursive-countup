# Recursive Countup in Python

A simple Python project demonstrating the use of **recursion** to generate a list of numbers from `1` up to a given number.

The `countup()` function uses a **base case** to stop the recursion and a **recursive case** to build the list step by step. This project is a practical example of how recursive functions work in Python.

## Example

```python
countup(5)
```

Output:

```text
[1, 2, 3, 4, 5]
```

## Concepts Demonstrated

* Python functions
* Recursion
* Base cases
* Recursive cases
* Lists and `append()`
* Function calls
